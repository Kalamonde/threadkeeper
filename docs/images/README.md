# Images for the README

Every image the README shows. Each one is either a mock-up of the desktop app with made-up data, or a cleaned crop of a real screenshot. Rules for all of them:

- Made-up thread names only. No real names, tickets, companies or file paths.
- PNG, about 1,400 px wide at most. Crop to the part that matters.
- Raw screenshots go in `docs/images/raw/` (ignored by git). Only checked copies go here.
