# Threadkeeper rules

Made by /threadkeeper:setup on {{INSTALLED_AT}}. Do not edit this file by hand. To change modules, run /threadkeeper:uninstall and then /threadkeeper:setup. To remove Threadkeeper, run /threadkeeper:uninstall.

Threadkeeper's files are in `{{TK_DIR}}`.

## Status icons

- The Threadkeeper mod puts one status icon at the start of each thread title: ⏳ working, ❓ waiting on the user, 🟢 reply ready, ⚠️ error, ✅ done, ⏰ snoozed (with the wake time after it, like `⏰ 11-23 Mon 09 `).
- When you rename a thread, keep its leading icon. The mod manages the icons: never add, change or remove one yourself.
- The bare title is the title without its leading icons and without the wake time after ⏰.

## Limits

- Never move, rename, close, archive or delete another thread unless the user asks for that thread. No bulk changes to threads.
- A scheduled task run (get_session "self" shows a scheduledTaskId) does not file, name, close, snooze or offer anything for its own thread. A run of a Threadkeeper task (its name is in `{{TK_DIR}}/tasks.json`) does only what its task text says.
- If a Threadkeeper step fails (a tool refuses, a section is missing, a file does not parse), say so in one line and suggest /threadkeeper:doctor. Do not work around it.
